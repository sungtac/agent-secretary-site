Agent Secretary

Agent Secretary는 개인이 자신의 Google 계정에서만 사용하는 비공개 자동화 도구입니다. 사용자의 캘린더와 드라이브에 일정과 파일을 기록하며, 외부에 배포되지 않고 일반 사용자를 대상으로 하지 않습니다.

Agent Secretary is a private, personal-use automation tool. It writes events and files to the owner's own Google Calendar and Google Drive. It is not distributed to or intended for the general public.
